This script will leverage FFMPEG to convert the DTS track of a video file to EAC3, then overwriting the existing video file with the new audio track.

USAGE:
1. install ffmpeg according to OS:
https://www.ffmpeg.org/

2. make script executable and run in terminal
3. drop video file in terminal when asked
4. wait for process to finish
5. repeat with (y) or end with (n)

Script is mainly made by Gemini 3.1 Pro
